# 📱 Minggu 02: Declarative UI & Responsive Design

Modul minggu kedua ini berfokus pada pemahaman paradigma Declarative UI pada Flutter, penggunaan widget dasar (Row, Column, Container, Expanded, Flexible), serta pembuatan layout yang responsif dengan `LayoutBuilder` dan `GridView`.

---

## 🎯 Tujuan Pembelajaran
- [x] **Layout Dasar**: Membangun komponen kartu profil (`ProfileCard`) menggunakan `Row`, `Column`, `Container`, dan `Expanded`.
- [x] **Aplikasi Responsif**: Membangun `Student Dashboard` yang menyesuaikan jumlah kolom berdasar lebar layar (breakpoint 700px) menggunakan `LayoutBuilder`.
- [x] **Interaktivitas & Tema**: Menggunakan `StatefulWidget` dan `CupertinoSwitch` untuk fitur *dark mode toggle*.
- [x] **Aksesibilitas**: Menambahkan widget `Semantics` pada elemen penting untuk *screen reader*.
